# PhotoChallengeBot

Телеграм-бот для фоточелленджей в одном основном чате.

## Что делает бот

- Админы из чата-админки создают челлендж с темой, хештегом и датами приема
  фотографий.
- Бот публикует и закрепляет анонс в основном чате.
- Участники присылают фотографии с хештегом челленджа.
- От одного участника в челлендже остается только одна актуальная фотография.
- Бот не удаляет и не редактирует фотографии участников в основном чате.
- После закрытия приема бот запускает двухдневное голосование в личке.
- Голосовать может любой пользователь, который открыл голосовалку по ссылке из
  основного чата.
- По итогам голосования бот публикует и закрепляет результаты в основном чате.
- Бот считает победы участников для ачивок.

Бот отправляет новому человеку в основном чате эфемерное приветствие с напоминанием прочитать закрепы и присылать свежие фотографии.
Сообщение видно только получателю и боту; Telegram не гарантирует доставку, если получатель офлайн.
Бот должен быть администратором основного чата с правом отправлять приветственные сообщения (`can_send_welcome_messages`).
Вступления обрабатываются через `chat_member`, поэтому изменение прав уже состоящего в чате человека не вызывает повторное приветствие.

## Как пользоваться

### Чаты и роли

- Основной чат - место, где участники видят анонсы, присылают фотографии и
  получают итоги.
- Чат-админка - место, где управляют челленджами.
- Админом считается любой человек, который пишет боту в чате-админке.

### Создать челлендж

В чате-админке отправьте одну из команд:

- `/challenge`
- `/new`
- `создать челлендж`

Бот пошагово спросит:

1. Тему челленджа.
2. Хештег в формате `#tag`.
3. Даты приема фотографий.

Для дат можно ответить:

- `ОК` - бот возьмет дефолтные даты: старт сегодня, последний день приема через
  17 дней;
- `YYYY-MM-DD` - бот оставит старт сегодня и возьмет указанную дату как
  последний день приема;
- `YYYY-MM-DD YYYY-MM-DD` - бот возьмет первую дату как старт, вторую как
  последний день приема.

После этого бот соберет текст анонса и пришлет его на проверку в админку.
Ответьте `ОК`, чтобы опубликовать предложенный текст, или отправьте свой текст
следующим сообщением. Подтвержденный анонс уйдет в основной чат и будет
закреплен.

Во время создания челленджа можно отправить обычную команду бота: она не станет
текстом анонса. `/challenge` или `/new` начнут создание заново, а `/cancel` или
`отмена` отменят текущий черновик.

### Принять фото на челлендж

Участник присылает фотографию в основной чат и добавляет к сообщению хештег
текущего челленджа. Если фото принято, бот отвечает в основной чат.

От одного участника в одном челлендже остается одна актуальная конкурсная
фотография. Если участник прислал новую фотографию с тем же хештегом, бот
заменит конкурсную запись на новую, но не будет удалять старое Telegram-сообщение
из чата.

Прием фотографий закрывается автоматически в 18:00 МСК в последний день приема.
За 30 часов до закрытия бот отправляет напоминание в основной чат.

### Удалить фото из текущего челленджа

В чате-админке отправьте:

- `/delete_photo @username`
- `/delete_photo 123456789`

Первый вариант удаляет конкурсную запись по username, второй - по Telegram user
ID. Бот удаляет только запись из конкурса, сообщения с фотографиями в основном
чате он не трогает.

### Голосование

После закрытия приема бот публикует в основной чат ссылку на голосование и
закрепляет сообщение. Голосование проходит в личке с ботом: по ссылке
открывается карточка фотографии с кнопками назад, вперед и лайк.

Голосовать можно за несколько фотографий. За себя голосовать нельзя: собственная
фотография автоматически получает self-like и кнопка лайка для нее не засчитывает
голос.

Голосование длится 2 суток. Досрочно завершить голосование можно из админки:

- `/finish_vote`
- `/finish_voting`
- `завершить голосование`

После окончания голосования бот публикует и закрепляет итоги в основном чате:
победителя или победителей с фото, затем все работы альбомами по 10 фотографий
с местом, автором и количеством голосов. Если участник выигрывает в 1, 3, 5 или
7 раз, бот отправляет сообщение про ачивку.

### Выбрать тему следующего челленджа

Во время голосования за фотографии участники предлагают темы в основном чате с хештегом `#тема`.
После завершения голосования, в том числе командой `/finish_vote`, бот отправляет полный список предложений с авторами в админский чат и публикует анонимный опрос с множественным выбором в основном чате.

Текст опроса: «Выбираем тему нового челленджа. Голосуем до пятницы, можно за несколько✨».
Администратор закрывает опрос вручную.

В опрос попадает не больше 12 вариантов.
Пока предложений больше 12, бот случайно выбирает автора с несколькими темами и удаляет одну случайную тему этого автора.
Когда у каждого осталось по одной теме, бот исключает случайных авторов до достижения лимита.
Если предложений изначально не больше 12, сохраняются все темы, включая несколько тем одного автора.

Бот убирает `#тема` и лишние пробелы из вариантов, пропускает пустые варианты и сокращает слишком длинные до 100 символов.
Если содержательных тем нет, опрос не публикуется.
После перезапуска уже опубликованный опрос повторно не отправляется; завершённые до обновления челленджи не получают опросы задним числом.

## Запуск

Для локального запуска через Docker Compose создайте `.env` по примеру
[.env.example](.env.example) и заполните:

- `TELEGRAM_BOT_TOKEN`
- `MAIN_CHAT_ID`
- `ADMIN_CHAT_ID`

По умолчанию база SQLite хранится в compose volume по пути
`/data/photochallengebot.sqlite`, шаблоны читаются из `/app/templates`, timezone -
`Europe/Moscow`.

```bash
docker compose up -d --build
```
